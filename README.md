### Financial Transaction Reconciliation Platform





## Problem Statement

Financial systems can contain duplicate transactions, missing records,

amount mismatches, and delayed settlements.





## Objective

Build a data engineering pipeline that processes financial transaction data,

identifies discrepancies, and produces reconciliation reports.



### Technology Stack

\- Python

\- SQL

\- PostgreSQL

\- PySpark

\- Git and GitHub
